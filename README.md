# Sentiment Analyzer

This is a simple web application that analyzes the sentiment of the text entered by the user.

It shows the result as:
- Positive
- Negative
- Neutral

## Technologies Used

- Python
- Flask
- HTML
- CSS
- TextBlob

## How to Run

1. Open the project in VS Code.
2. Activate the virtual environment.
3. Run:

   python app.py

4. Open the local link shown in the terminal.

## About the Project

I created this project to practice Python and Flask and to understand the basic concept of sentiment analysis.
